# Agentic Banking Knowledge Assistant

This project implements a multi-agent RAG architecture using:
- Gemini Pro
- LangGraph
- ChromaDB
- Streamlit
- HuggingFace Embeddings

## Agents
1. Planner Agent
2. Retrieval Agent
3. Reasoning Agent
4. Validation Agent

## Features
- Document Upload (.pdf, .txt, .csv, .xlsx)
- Semantic Search
- Agentic Workflow
- Hallucination Reduction
- Source Grounding
- Multi-format Support
